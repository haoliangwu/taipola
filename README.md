# Taipola

> **这是一个娱乐项目。** 代码由 **deepseek-v4.1-flash** 以"许愿式编程"的方式写成：描述想要的
> 效果、模型实现、跑测试、看结果。
>
> 它图的是好玩，不是生产可用。哪天这个项目要认真做了，这里会换成一份正式的 README。

除了名字是我起的，剩下都是大肥鱼做的。

**[在线 DEMO](https://haoliangwu.github.io/taipola/)** 纯静态，点开就能用，不用装任何东西。

- **像 Typora 的用法**，所见即所得。
- **不是套壳，** 没有引入任何现成的编辑器内核，不过引入了 `markdown-it` 来做分块检测。
- **CJK 输入法友好，** 拼音候选、联想词不受干扰。
- **内容不会丢，** 草稿自动写进 localStorage，关掉页面再回来还在。
- **能落到文件，** 打开 / 保存 md，浏览器支持时写回原文件（File System Access API），否则降级为下载。
- **技术栈很普通，** Vite + React 19 起壳，编辑器内核是原生 javascript。

## 本地跑起来

```bash
pnpm install
pnpm dev          # http://localhost:5178
pnpm build        # 产出 dist/
pnpm test         # 两层：纯函数(unit) + 真实 Chromium
```

## 包含哪些功能

- 即时渲染段落、标题、列表、引用、代码块、表格、任务列表、脚注
- 撤销 / 重做走自带的快照栈，恢复时连光标一起还原
- 侧边大纲随光标高亮所在章节，点击跳转
- 导出 HTML / 导出 MD
- 主题默认跟随系统，可切换 浅色 / 深色 / 跟随系统
- 快捷键对齐 Typora 的 macOS 键位表：

  | 键 | 功能 |
  | --- | --- |
  | ⌘B / ⌘I / ⌘K | 粗体 / 斜体 / 链接（Cmd+Ctrl 同） |
  | ⌃` / ⌃⇧` | 行内代码 / 删除线（Ctrl 系仅 Control，不含 Cmd） |
  | ⌃M | 行内数学 |
  | ⌘1–⌘6 / ⌘0 | 标题 1–6 级 / 还原为普通段落 |
  | ⌘= / ⌘+ / ⌘- | 标题升一级 / 降一级（浏览器缩放键被编辑器占用） |
  | ⌘\ | 清除格式（只剥行内标记；浏览器隐藏书签栏键被占用） |
  | ⌥⌘Q / ⌥⌘U / ⌥⌘O / ⌥⌘X | 引用 / 无序 / 有序 / 任务列表切换（Alt+Cmd 或 Alt+Ctrl） |
  | ⌘] / ⌘[ | 列表缩进 / 反缩进（与 Tab / Shift+Tab 同语义） |
  | ⌥⌘C / ⌥⌘T | 代码块 / 表格 |
  | ⌥⌘R / ⌥⌘L | 脚注 / 链接引用（定义行追加文末） |
  | ⌥⌘- | 水平线 |
  | ⌘S / ⌘⇧S / ⌘O / ⌘⇧O / ⌘N | 保存 / 另存为 / 打开 / 打开文件夹 / 新建 |
  | ⌘⇧K / ⌘⇧\ | 删除整行 / 大纲开关 |
  | Esc | 离开编辑区 |

  表格里另有一套：`Tab` / `⇧Tab` 在格子间走（最后一格再按 `Tab` 加一行），
  `⌘⏎` / `⇧⌘⏎` 在当前行下面 / 上面插一行，`⇧⌘⌫` 删掉当前行。增删列、对齐
  和删除整张表在**格子里的右键菜单**上。

## 已知的限制

即是限制，也是 backlog 列表：

- mermaid 和 display 数学（`$$…$$`）还没有；行内数学（`$…$` / `\(…\)` / `\[…\]`）
  编辑器内渲染，导出仍为源码。
- 表格各列等宽，不按内容自适应（`| :--- |` 这类对齐写法编辑器内不生效，导出才生效）。
- 表格的列命令只在右键菜单里（Typora 也是这样）；键盘只有行命令。
- 单文档全量重解析，几万行的文件会有输入延迟。
- 测试只跑在真实 Chromium 上，没有跨浏览器矩阵。
- 图片加载完成后会引起一次布局位移，光标进图片构造时才折叠回源码。
